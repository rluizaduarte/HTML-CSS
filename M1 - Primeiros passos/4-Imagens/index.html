A tag img

Carregando imagens na mesma pasta do arquivo HTML

Aprendendo a usar a tag img que insere imagens no HTML

Pra carregar a imagem é só usar a tag img, colocar a origem do arquivo no valor do parametro src (source) e um texto alternativo no parametro alt (alternative)

Devido ao formato exagerado da imagem, a visualização fica extemamamente difícil. Por isso, é recomendado redimensionar a imagem em tamanhos menores.

É importante diminuir o tamanho da imagem tanto pra que faça sentido com as proporções do site quanto pra deixar o carregamento mais rápido, pois a imagem será mais leve.

Carregando imagens que estão numa sub-pasta dentro da pasta do arquivo HTML

Pra fazer isso é só colocar o caminho da sub-pasta antes do nome do arquivo no valor do parâmetro src (source).

Carregando imagens com links

Também é possível carregar imagens externas pelo arquivo HTML. Basta colar a url da imagem no valor do parâmetro src (source).
