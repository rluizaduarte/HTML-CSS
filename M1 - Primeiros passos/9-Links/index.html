Estudando os links

Link Externo

Um link externo é um link que vai apontar pra outro site, que não é esse.

A tag responsável por transformar uma parte do corpo do texto em link é a tag a (anchor).

Essa tag pede um parametro chamado href (hypertext reference). O valor desse parâmetro é a URL para onde o link vai redirecionar. Além do parâmetro, devemos fornecer o texto que será exibido como link.

Exemplo de link externo:

  • Google
  • GitHub
  • YouTube
É importante que a url esteja completa, com o protocolo (http:// ou https://), o sub-dominio (www), a tld (.com, .org, etc.), o caminho completo e a âncora (se houver).

Esses links externos, no entanto, estão sobrepondo o site atual. Para que isso não aconteça, devemos passar outros parâmetros na tag a. O atributo target="_blank", serve para abrir o link em uma nova aba. O atributo rel="external", serve para indicar que o link é externo.

Perceba a diferença nos novos links:

  • Google
  • GitHub
  • YouTube

Link Interno

Um link interno é um link que aponta para outra página do mesmo site.

Link para download

Um link para download é um link que permite baixar um arquivo do servidor.

Para criar um link para download, devemos usar o atributo href com o caminho do arquivo que queremos baixar, junto com o atributo download e o atributo type com o media-type adequado.

Procure aqui o media-type adequado pra colocar como valor do atributo type:

  • Site de assignments do media-type

Exemplo de link para download:

  • Download do arquivo JPG
  • Download do arquivo ZIP
