Estudando mais formatações

Código-fonte

Para representar um código-fonte, utilizamos a tag code. Ela é particularmente útil para destacar trechos de código em um texto, como em tutoriais ou documentação técnica.

console.log("Hello, World!");

No entanto, quando um comando possui mais de uma linha e queremos respeitar a indentação, utilizamos a tag pre. A tag pre preserva os espaços em branco e a formatação do texto que foram escritos dentro do próprio documento HTML.

            
function saudacao() {
    console.log("Olá, mundo!");
}

Citação

Citações simples

Pra fazer uma citação, basta usar a tag q (quote), que adiciona aspas ao texto selecionado. São citações simples e sem quebra.

Citações em bloco

Já para fazer uma citação em bloco, ou seja, uma citação que ocupa um espaço separado do texto principal, utilizamos a tag blockquote. Essa tag faz uma quebra de linha e adiciona margens ao redor do conteúdo.

Ainda no bloco de citação, podemos adicionar mais detalhes ou contextos sobre a afirmação apresentada. Isso é possível com o parâmetro cite. Visualmente não há diferença para o bloco, mas internamente é importante. Como valor desse parâmetro, basta usar o URL da fonte original.

Abreviações

Estou estudando HTML. A tag usada pra abreviar é a tag abbr, que tem o parâmetro title e o texto abreviado. Quando o mouse está em cima dessa abreviação, o título é exibido.
