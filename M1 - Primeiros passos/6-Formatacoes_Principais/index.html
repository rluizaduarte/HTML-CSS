Estudando formatação em HTML

O conceito de semântica

Semântica é o estudo do significado das palavras e expressões em um idioma. Em HTML, a semântica se refere ao uso de tags que descrevem o conteúdo de uma página de forma clara e significativa.

O HTML5 é conhecido por sua abordagem mais semântica. O objetivo aqui é que a preocupação do desenvolvedor seja com o significado do conteúdo, e não com sua apresentação visual (ainda).

Hierarquia de títulos

Em HTML, as tags de título H1, H2, ..., H6 não servem apenas pra definir o tamanho do texto, até porque isso já não é mais semântico, mas para estruturar o conteúdo de forma lógica e significativa.

O H1 é o título mais importante, e deve ser usado para o título principal da página. O H2 é usado para subtítulos, e assim por diante, até o H6, que é o título menos importante.

Negrito

Para aplicar negrito em um texto, utilizamos a tag b. A tag b é uma tag de formatação que não possuem significado semântico.

Já nesta frase, onde há um termo de destaque, o uso da tag strong é recomendado. Aqui o significado semântico é mais importante que a apresentação visual.

Itálico

Para aplicar itálico em um texto, utilizamos a tag i.A tag i é uma tag de formatação que não possui significado semântico

Já nesta frase, onde há um termo de ênfase, o uso da tag em é recomendado. Aqui o significado semântico é mais importante que a apresentação visual.

Texto marcado

Usa-se a tag mark para destacar um texto, como se fosse um marca texto mesmo. O uso da tag mark é recomendado quando queremos destacar um trecho específico de um texto, como uma palavra-chave ou uma informação importante.

Pra trocar a cor do fundo da marcação, já é necessário usar as CSS. Basicamente, na abertura da tag mark, podemos definir a cor do fundo (com background-color) e a cor do texto (com color). Essa configuração servirá somente para esse mark.

Pra configurar o mark padrão (que servirá pra todos os outros que não tiver especificação na abertura da tag), o style estará presente no head do documento.

Tamanho dos textos

Apesar de já ter caído em desuso, a tag big do html era utilizada com o propósitos de aumentar o tamanho do texto. No entanto, se entendeu que essa abordagem não era mais semântica, pois letras maiores não possuem significado.

Ao contrario da tag small, que possui o significado semântico de indicar texto menor, como notas de rodapé, legenda, copyright.

De modo geral, essas duas funções agora são atribuidas às CSS.

Texto deletado

Para aplicar deletado em um texto, utilizamos a tag del. A tag del é uma tag de formatação que não possui significado semântico.

Já nesta frase, onde há um termo riscado, o uso da tag s é recomendado. Aqui o significado semântico é mais importante que a apresentação visual.

Texto sublinhado

Para aplicar sublinhado em um texto, utilizamos a tag u. A tag u é uma tag de formatação que não possui significado semântico.

Já nesta frase, onde há um termo sublinhado, o uso da tag ins é recomendado. Aqui o significado semântico é mais importante que a apresentação visual.

Texto sobrescrito

Para representar um texto sobrescrito, utilizamos a tag sup. Ela é particularmente útil para indicar expoentes em fórmulas matemáticas.

Texto subescrito

Para representar um texto subescrito, utilizamos a tag sub. Ela é particularmente útil para indicar índices em fórmulas matemáticas.
