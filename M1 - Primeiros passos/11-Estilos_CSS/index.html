Estudando as formas de estilizar elementos

Estilos em linha

O estilo em linha é aplicado diretamente a tag no elemento HTML. Na mesma abertura de tag, podemos usar o atributo "style" para definir estilos específicos.

Este parágrafo tem um estilo em linha, com texto vermelho e tamanho de fonte 30px.

Essa abordagem tem duas principais desvantagens:

  • Poluição do códigoo: cada elemento (tag) precisaria ter seu próprio estilo em linha.
  • Dificuldade de manutenção: se for necessário alterar um estilo, seria preciso modificar cada elemento individualmente, o que pode ser trabalhoso e propenso a erros.

O ideal é que os estilos fiquem separados do conteúdo HTML.

Estilos internos

Os estilos internos são definidos dentro da própria página HTML, usando a tag "style" dentro do elemento "head".

Esse style servirá para aplicar estilos a todos os elementos da página em que ela for escrita. Ela não aplica a outros arquivos.

Essa abordagem tem duas principais desvantagens:

  • Estilos com mais linhas: geralmente os estilos consomem mais espaço no código, o que pode dificultar a leitura e a manutenção.
  • Reutilização limitada: os estilos internos só se aplicam à página em que estão escritos, o que dificulta a reutilização em outras páginas do site.

Estilos externos

Os estilos externos são definidos em arquivos separados, com a extensão .css, e são vinculados à página HTML usando a tag "link" dentro do elemento "head".

Essa abordagem permite que os estilos sejam reutilizados em várias páginas do site, facilitando a manutenção e a consistência visual.
