Estudando Mídias em HTML

Imagens Dinâmicas

Para configurar a imagem que iremos colocar, utilizaremos a tag <picture>. Essa tag pode receber como parâmetro diferentes fontes de imagem, permitindo que o navegador escolha a mais adequada. Ainda dentro dela, podemos usar o source.Essa tag permite especificar múltiplas fontes para a mesma imagem, possibilitando uma melhor otimização para diferentes dispositivos e resoluções.

A tag source media type recebe o atributo media, que especifica a condição sob a qual a imagem associada deve ser exibida. Se o navegador atender a condição, a imagem será exibida, se não, a imagem padrão será exibida.

Áudios

Pra reproduzir áudio da forma mais simples é só usar a tag audio e passar o caminho do arquivo de áudio como atributo src. Isso por si só não abre o audio assim que abre o site. Pra fazer isso, tem que passar o atributo controls e o autoplay junto. E se quiser que a musica fique em loop, pode usar o atributo loop.

Outra forma de reproduzir áudio é usando a tag <audio> com o atributo <source> para especificar múltiplas fontes de áudio.

Por ordem, o site tenta rodar os sources.

Vídeos

Em hospedagem própria

Assim como imagens e audio, é simples colocar vídeos no site usando a tag <video>. A tag video tem os mesmos atributos do audio, como controls, autoplay e loop. E também tem a tag source para especificar múltiplas fontes de vídeo.

Especificar multiplas fontes de video com o source é importante porque o site pode ser carregado em diferentes navegadores e dispositivos.

No caso a cima o autoplay e o loop estão ativados, mas caso não esteja e queira colocar uma imagem padrão, pode usar o atributo poster.

Em hospedagem externa

Também é possível colocar vídeos hospedados em plataformas externas, como o YouTube. Para isso, podemos usar a tag <iframe> para incorporar o vídeo diretamente na página.

Isso ajuda a diminuir o tamanho do site e a melhorar o desempenho.

Lá no próprio YouTube, ao selecionar a opção compartilhar no vídeo, é possível obter o código de incorporação.
