Estudando as Listas

Existem 3 tipos de listas: ordenada, não ordenada e de definição.

Listas Ordenadas

As listas ordenadas são utilizadas quando a ordem dos itens é importante. Cada item é numerado automaticamente. Pra isso usamos a tag ol (ordered list) e a tag li (list item).

  1. Primeiro item
  2. Segundo item
  3. Terceiro item

A tag já quebra as linhas e adiciona margens ao redor do conteúdo. Posso mudar a formatação da lista usando estilos CSS com o parâmetro type.

  1. Primeiro item
  2. Segundo item
  3. Terceiro item
  1. Primeiro item
  2. Segundo item
  3. Terceiro item
  1. Primeiro item
  2. Segundo item
  3. Terceiro item
  1. Primeiro item
  2. Segundo item
  3. Terceiro item

Listas Não Ordenadas

A sequência aqui não é importante. Cada item é marcado com um bullet. Pra isso usamos a tag ul (unordered list) e a tag li (list item).

  • Pão
  • Leite
  • Ovos

Também posso mudar a formatação da lista usando estilos CSS com o parâmetro type.

  • Pão
  • Leite
  • Ovos
  • Pão
  • Leite
  • Ovos

Lista de Definição

Nas listas de definição, cada item é composto por um termo e sua definição. Para isso usamos a tag dl (description list), a tag dt (description term) e a tag dd (description description). É como se fosse um dicionário.

HTML
Linguagem de marcação para criar páginas web.
CSS
Linguagem de estilo para definir a aparência das páginas web.

Junção de Listas

Posso juntar os tipos de listas. Por exemplo, uma lista ordenada com uma lista não ordenada dentro dela.

Ul(ou Ol) dentro de Ol(ou Ul)

  1. Segunda-feira
    • Trabalho
    • Academia
  2. Terça-feira
    • Trabalho
    • Festa
  3. Quarta-feira
    • Faculdade
    • Compras

Ul(ou Ol) dentro de Ul(ou Ol)

  • Pesquisa
    • PIBIC
  • Faculdade
    • Árvores
    • Redes
    • Robótica
