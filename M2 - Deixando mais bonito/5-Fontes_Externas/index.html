Inserindo fontes novas

Links

Existem diversas ferramentas que possibilitam a inserção de fontes externas em um projeto web.A principal é a Google Fonts, onde podemos selecionar a opção "Embed" e copiar o link para o nosso projeto. Claramente essa fonte só estará disponível se o usuário tiver acesso à internet.

Então usamos a regra @import no CSS. Por exemplo:


    @import url('https://fonts.googleapis.com/css2?family=Modak&display=swap');

Fontes baixadas

Também é possível baixar uma fonte e inseri-la no projeto. Para isso, devemos usar a regra @font-face. Por exemplo:


    @font-face {
        font-family: "Minha Fonte";
        src: url("caminho/para/a/fonte.ttf");
    }
