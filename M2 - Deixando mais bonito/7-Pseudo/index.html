Classes

Já vimos que as pseudo-classes são usadas para aplicar estilos a elementos com base em seu estado ou posição na hierarquia do documento.

Pseudo-classes estudadas

  1. :hover

    Aplicado quando o mouse passa por cima do elemento

  2. :focus

    Aplicado quando o elemento está em foco

  3. :visited

    Aplicado quando o link foi visitado

  4. :active

    Aplicado quando o elemento está ativo

Aplicação das pseudo-classes estudadas

Alguns links:

  • Google
  • GitHub
  • Stack Overflow

A pseudo-classe A faz com que algo seja feito quando o mouse passa por cima do elemento. Portanto, aplicando:

    a:hover {
        color: red;
    }

Faz com que a cor do link fique vermelha quando o mouse passar por cima

A pseudo classe B faz com que algo seja feito quando o elemento está em foco. Portanto, aplicando:

    a:focus {
        color: blue;
    }

Faz com que a cor do link fique azul quando o elemento estiver em foco (mouse clicou nele e ainda tá aberto ou tá segurando o mouse).

A pseudo-classe C faz com que algo seja feito quando o link foi visitado. Portanto, aplicando:

    a:visited {
        color: purple;
    }

Faz com que a cor do link fique roxa quando o link foi visitado.

A pseudo-classe D faz com que algo seja feito quando o elemento está ativo. Portanto, aplicando:

    a:active {
        color: orange;
    }

Faz com que a cor do link fique laranja quando o elemento estiver ativo (mouse clicou nele e ainda tá segurando o mouse).

Elementos

As pseudo-elementos são usadas para criar elementos virtuais que não existem no HTML, mas que podem ser estilizados usando CSS.

Pseudo-elementos estudados

  1. ::before

    Cria um elemento virtual antes do conteúdo do elemento selecionado

  2. ::after

    Cria um elemento virtual depois do conteúdo do elemento selecionado

Aplicação das pseudo-elementos estudados

Aplicando:

    li::before {
        content: "Antes: ";
        font-weight: bold;
    }
    li::after {
        content: " :Depois";
        font-weight: bold;
    }

Faz com que o texto "Antes: " seja adicionado antes do conteúdo de cada item da lista e o texto " :Depois" seja adicionado depois do conteúdo de cada item da lista.
