Pseudo-Classes

Estado de Elementos

Passe o mouse por cima das divs para ver o efeito da pseudo-classe :hover.

Uma pseudo-classe está relacionada a um estado específico de um elemento, como quando o mouse passa por cima dele ou quando ele é o primeiro filho de seu pai.
As pseudo-clases são usadas para aplicar estilos a elementos com base em seu estado ou posição na hierarquia do documento.
Um exemplo de pseudo-classe é a ":hover", que é aplicada a um elemento quando o mouse passa por cima dele.

Esse texto está dentro de uma div. Também existe um parágrafo escondido, o qual é filho da div, somente por estar dentro dela. Passe o mouse por cima desse texto para ver.
