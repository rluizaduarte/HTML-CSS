O problema dos IDs

Dentro de um mesmo documento HTML, só se pode ter um elemento com um determinado ID. Se o ID "principal" foi usado na primeira h1, nenhum outro elemento pode ser principal também.

Classes em CSS

Ao contrário dos IDs, que só permitia uma instância por página, as classes podem ser aplicadas a múltiplos elementos.

Todos os títulos, exceto esse, pertencem a classe "titulos"

A tag span

A tag span é usada para agrupar elementos inline e aplicar estilos a partes específicas do texto. Com ela, é possível atribuir um elemento dentro de um elemento a alguma classe.

Elementos com mais de uma classe

Um elemento pode pertencer a mais de uma classe. Para isso, basta separar os nomes das classes por um espaço.

Esse título pertence a classe "titulos" e "ariais"

O elemento com mais de uma classe herda as configurações de ambas as classes.
