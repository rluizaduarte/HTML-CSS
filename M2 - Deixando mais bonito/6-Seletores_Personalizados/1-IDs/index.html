Uso de IDs

O id é um atributo que permite identificar unicamente um elemento na página. Aqui estamos identificando o título principal do site como "titulo-principal". Isso diferencia os elementos na página.

Título sem ID

Este é um título que não possui um ID específico.

Título secundário

Este é um título secundário que possui um ID específico, "titulo-secundario".

Manipulando os IDs

Lá no arquivo CSS, ao abrir um seletor h1 com o símbolo #, seguido do nome do ID, estamos selecionando o elemento com o ID especificado. As configurações dentro desse seletor serão aplicadas apenas ao elemento com o ID correspondente.
