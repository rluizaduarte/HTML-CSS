Agrupamento de Tags

Todo site tem o cabeçalho (header), que é a apresentação do site, o conteúdo principal (main), que é a essência do site, e o rodapé (footer), que é onde tem alguns links, informações de contato e outros elementos.

Cabeçalho

Utilizamos a tag <header> para criar o cabeçalho do site.

Conteúdo Principal

Utilizamos a tag <main> para criar o conteúdo principal do site.

Rodapé

Utilizamos a tag <footer> para criar o rodapé do site.

Importância

Separando o site com essas tags, podemos organizar muito bem o conteúdo e estilizar com muito mais tranquilidade.
