Caixas

Todo o site é construído com caixas. Cada tag representa uma caixa no modelo de caixas do CSS.

O modelo de caixas é composto por quatro partes: conteúdo, preenchimento, borda e margem.

Conteúdo

O conteúdo é a parte central da caixa, onde o conteúdo real do elemento é exibido. Tem uma largura (width) e altura (height) específicas. Essas características definem o tamanho do conteúdo dentro da caixa e podem ser modificadas.

Este parágrafo tem uma largura de 50% e uma altura de 100px.

Preenchimento

O preenchimento (padding) é a área entre o conteúdo e a borda da caixa. Ele pode ser definido com valores específicos para cada lado (top, right, bottom, left).

Este parágrafo tem um preenchimento de 20px em todos os lados.

Borda

A borda (border) é a linha que delimita a caixa. Ela pode ser definida com valores específicos para cada lado (top, right, bottom, left).

Este parágrafo tem uma borda de 2px sólida e preta.

Margem

A margem (margin) é a área entre a borda da caixa e os elementos adjacentes. Ela pode ser definida com valores específicos para cada lado (top, right, bottom, left).

Este parágrafo tem uma margem de 50px em todos os lados.

Tipos de Caixas

Box-level

As caixas de nível de bloco (block-level) ocupam toda a largura disponível e começam em uma nova linha. Exemplos incluem <div>, <p> e <h1>.

Inline-level

As caixas inline ocupam apenas o espaço necessário para o conteúdo e não começam em uma nova linha. Exemplos incluem <span> e <a>.

Inline-block

As caixas inline-block combinam características de ambos os tipos anteriores. Elas ocupam apenas o espaço necessário para o conteúdo, mas também permitem definir largura e altura. Exemplos incluem <img> e <button>.
