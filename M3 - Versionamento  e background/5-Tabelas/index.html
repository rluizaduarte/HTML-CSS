Tabelas

Antigamente as tabelas eram utilizadas para estruturar sites. Isso se descontinuou porque se tornava dificil a manutenção e a adição de novos componentes. Portanto, atualmente as tabelas são usadas ainda como exibição de dados, mas não como layout da página.

A tag <table> é utilizada para criar tabelas em HTML.

Hierarquia simples


TABLE - tabela 
  TR - table row (linha)
    TH - table header (cabeçalho)
    TD - table data (celula de dados)

Ou seja, pra cada <tr> temos <th> ou <td>.

Exemplo de tabela simples

Coluna A Linha 1 Coluna B Linha 1 Coluna C Linha 1
Coluna A Linha 2 Coluna B Linha 2 Coluna C Linha 2
Coluna A Linha 3 Coluna B Linha 3 Coluna C Linha 3
Coluna A Linha 4 Coluna B Linha 4 Coluna C Linha 4

Propriedade especial da borda

Quando se utiliza a propriedade border-collapse: collapse; a borda da tabela e das células se fundem, diferentemente da configuração padrão border-collapse: separate;, que deixa um espaço entre as bordas das células.

Alinhamento horizontal

Usa-se text-align: center.

Alinhamento vertical

Usa-se vertical-align: middle.

Mesclagem de células

Existem duas formas de mesclar uma célula:

  • rowspan: mescla células em linhas
  • colspan: mescla células em colunas
Para usar uma delas, basta adicionar o atributo equivalente (se quer mesclar por linha ou por coluna) na tag <td> ou <th> que deseja mesclar. Por exemplo, se você quiser mesclar duas células em uma linha, você adicionaria rowspan="2" na célula que deseja mesclar. Se quiser mesclar duas células em uma coluna, você adicionaria colspan="2".

Exemplo de tabela com mesclagem

Coluna A Linha 1 e Linha 2 Coluna B e Coluna C Linha 1
Coluna B Linha 2 Coluna C Linha 2
Coluna A Linha 3 Coluna B Linha 3 Coluna C Linha 3
Coluna A Linha 4 Coluna B Linha 4 Coluna C Linha 4
