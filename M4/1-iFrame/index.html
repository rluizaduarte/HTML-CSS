O que é?

Um iFrame é um Frame inline, ou seja, um elemento que permite incorporar outro documento HTML dentro do documento atual.

É como um moldura só que o conteúdo dentro dela é carregado de forma independente.

Proteções

Existem alguns sites que proibem o uso de iFrames.

Incompatibilidade

Caso não funcione, é possivel colocar o site dentro do iframe como plano B.
