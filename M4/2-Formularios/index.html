Criando o primeiro formulário

Basicamente os formulários servem pra coletar dados do usuário.

Forma geral

Todo formulário tem que estar entre as tags <form> e </form>. Dentro de um formulário, além de vários atributos possíveis, temos os elementos de entrada, como campos de texto, botões, etc. Também é possível colocar paragrafos e etc.

Pra onde mandar os dados?

Normalmente se manda pra alguma linguagem de programação. Nesse curso usa-se PHP.

Por ora esses dados estarão na URL. O "?" divide o dominio dos dados que mandei.

Metodos

  • GET: metodo padrão, esse que fica no link.
  • POST: não exibe os dados na URL. os dados ficam no headers do network em inspecionar.

Atributos na tag forms

  • autocomplete: por padrão é "on", mas pode ser "off". É a sugestão de valor pra o input (valores que já coloquei antes)
  • action: ação disparada ao clicar no botão de submit, por exemplo.
  • method: define o metodo HTTP que ta sendo utilizado. Por padrão é GET.

Atributos na tag input

  • type: define o tipo do input. Por padrão é "text".
  • name: nome do input, que é o que vai ser enviado pro servidor.
  • id: id do input, que é o que vai ser usado no label.
  • value: valor do input, que é o que vai ser enviado pro servidor.
  • placeholder: texto de sugestão dentro do input.
  • required: define se o input é obrigatório ou não.
  • size: define o tamanho do input.
